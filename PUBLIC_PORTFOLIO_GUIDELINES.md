# Public Portfolio Guidelines

This repository is designed to demonstrate the Intelligent Scheduling Assistant publicly without exposing private implementation details, credentials, or personal calendar information.

## Safe to Publish

- Illustrative workflow visuals with fictional data
- Fictional meeting and calendar data
- High-level capabilities
- High-level architecture diagrams
- Product goals and business value
- General workflow descriptions
- Public portfolio documentation

## Keep Private

- Source code unless intentionally open-sourced
- API keys, secrets, tokens, cookies, and OAuth credentials
- Real calendar IDs or event IDs
- Personal or customer calendar data
- Real attendee names, email addresses, or meeting links
- Provider-specific authentication implementation
- Detailed prompts, system instructions, or tool schemas
- Proprietary scheduling logic, ranking rules, or approval rules
- Internal architecture diagrams that expose implementation details
- Customer-specific integrations or commercial roadmap

## Before Publishing Any New Screenshot

Confirm that the screenshot contains no:

1. Real names or email addresses
2. Real meeting titles or locations
3. Calendar IDs, meeting URLs, or conference links
4. API keys, secrets, tokens, or credentials
5. Customer or employer information
6. Proprietary prompt or orchestration details
7. Sensitive personal scheduling information

## Portfolio Accuracy

Clearly distinguish among:

- **Working capability** — tested in a functioning environment
- **Prototype capability** — designed and demonstrated in a prototype workflow
- **Planned capability** — part of the product roadmap but not yet demonstrated

The current public images are illustrated workflow visuals with fictional data. They are not live app screenshots or evidence of verified integrations.
